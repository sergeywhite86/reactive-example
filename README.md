# Reactive User API

Реактивное REST API на Spring Boot 4 + R2DBC + PostgreSQL.

## Технологический стек

- **Java 21**
- **Spring Boot 4.0.6**
- **Spring WebFlux**
- **Spring Data R2DBC**
- **PostgreSQL 16**
- **Liquibase** 
- **MapStruct 1.6.3**
- **Lombok**
- **SpringDoc OpenAPI (Swagger)**
- **Docker + Docker Compose**

---
